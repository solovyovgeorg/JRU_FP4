Выполнение финального задания JR Модуль 4. Так как задание подразумевает ctrl+c\ctrl+v, от себя добавлено только:
Заменены зависимости проекта на свежие.
Секреты вынесены в .env и не фигурируют в коде. Redis остался с открытым доступом.
Осуществлено развертывание через docker compose для взаимодействия контейнеров (MySql, Redis, App), 
сделан также механизм инициализации MySql скриптом с задания (использован healthheck контейнера MySql)
Слегка адаптирован старый код подключения Hibernate в связи с использованием более свежей версии.
Приложение выполняется в две стадии: 1) Сборка в uber Jar. 2) Запуск Jar в контейнере.
Для запуска приложения в директории проекта необходимо выполнить docker compose up --build
