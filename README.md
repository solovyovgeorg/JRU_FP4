# Выполнение финального задания JR Модуль 4

Так как задание подразумевает `Ctrl+C / Ctrl+V`, от себя добавлено только:

- Заменены зависимости проекта на свежие версии.
- Секреты вынесены в `.env` и не фигурируют в коде.
- Redis остался с открытым доступом.
- Осуществлено развертывание через `Docker Compose` для взаимодействия контейнеров:
  - MySQL
  - Redis
  - App
- Реализован механизм инициализации MySQL скриптом из задания. Для ожидания готовности MySQL используется `healthcheck` контейнера.
- Слегка адаптирован старый код подключения Hibernate в связи с использованием более свежей версии Hibernate.
- Приложение выполняется в две стадии:
  1. Сборка в `uber JAR`.
  2. Запуск `JAR` в отдельном контейнере.

## Запуск

Для запуска приложения в директории проекта необходимо выполнить команду docker compose up --build
